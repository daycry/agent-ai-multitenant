# Plan 06.7 — tests humanos

Esta guía cubre los **2 tests humanos** del Plan 06.7 (Detector de
memorias similares + tenant-settings genéricos categorizados). Ambos
son una navegación UI guiada por `/admin/settings` y `/admin/memories`.

> **Estado del plan**: `completed` (mergeado a master). La guía queda
> para regresión visual al tocar la página de settings o el dedup
> detector.

## TL;DR

```powershell
.\scripts\dev\up.ps1                                       # primera vez
.\.venv\Scripts\python.exe scripts\demos\setup_demo_project.py   # proyecto + agente compartidos
.\.venv\Scripts\python.exe scripts\demos\setup_demo_06_6_7.py    # 4 memorias con embeddings sintéticos
# luego: abre el admin-panel y recorre los checklists
```

`setup_demo_06_6_7.py` siembra **cuatro memorias**:

| Memoria | Embedding                             | Para qué                             |
| ------- | ------------------------------------- | ------------------------------------ |
| A       | Vector base + ruido gaussiano pequeño | Par cercano con B (cos ≈ 0.92)       |
| B       | Vector base + otro ruido gaussiano    | Par cercano con A                    |
| C       | Vector aleatorio independiente        | NO matchea con A/B (cos ≈ 0)         |
| D       | `embedding=NULL`                      | Verifica que el detector las excluye |

## `human_06_7_01` — tenant-settings genéricos con iconos

**Qué prueba**: la nueva página `/admin/settings` muestra cards
categorizadas con iconos (Memorias, Costes) y cada categoría tiene
su sub-página dedicada que persiste cambios.

**Cómo ejecutarlo**:

1. Login en el admin-panel.
2. Sidebar → "Settings" → debe llevar a `/admin/settings` (NO a
   `/admin/settings/hourly-rate` directamente como antes).
3. Verifica las cards:
   - **Memorias** (icono cerebro) → click → `/admin/settings/memories`.
   - **Costes** (icono monedas) → click → `/admin/settings/hourly-rate`
     (página dedicada existente).
4. En `/admin/settings/memories`:
   - El `PageHeader` tiene el mismo icono cerebro de la card.
   - Hay un formulario con `threshold` (slider 0.5 – 0.99) y `limit`
     (input 1 – 20).
   - Cambia el threshold a `0.75`, guarda. La UI confirma "guardado".
   - F5 → los nuevos valores siguen ahí.

**Checklist**:

- [ ] `/admin/settings` muestra al menos las cards Memorias + Costes
      con sus iconos.
- [ ] Click en Memorias lleva a `/admin/settings/memories` con el
      mismo icono en el `PageHeader`.
- [ ] Formulario permite cambiar threshold (slider 0.5 – 0.99) y
      limit (1 – 20).
- [ ] PUT persiste — F5 muestra los valores nuevos.
- [ ] Click en Costes lleva a `/admin/settings/hourly-rate`
      (página existente).
- [ ] Sidebar → "Settings" apunta a `/admin/settings`, NO a la
      sub-página hourly-rate.

**Pitfalls conocidos**:

- Si el `threshold` no se persiste tras F5, probablemente el endpoint
  `PUT /tenant-settings/memories/threshold` está devolviendo 422
  (registry strict). Revisa la consola del navegador y mira
  `apps/api-server/src/api_server/settings_registry.py`.

## `human_06_7_02` — detector de memorias funciona end-to-end

**Qué prueba**: el badge "N similares" aparece en la card de una
memoria con par parecido; el modal lista candidatos con su % de
similitud; las acciones Fusionar / Descartar funcionan.

**Cómo ejecutarlo**:

1. Login + sidebar → "Memorias".
2. Tu listing debe incluir las 4 memorias del seed (filtra por
   `scope=team_shared` o por el contenido si hay ruido).
3. En la card de **A**, debe verse un badge amarillo "1 similar" (o "N
   similares" si re-corres el seed varias veces).
4. Click en el badge → se abre un modal con la lista de candidatos
   (cada uno con su % cosine sim — debería rondar el 92 %).
5. Click "Fusionar" en el candidato (B) → diff de contenidos, confirmar.
   B queda soft-deleted, A absorbe el contenido (o el comportamiento
   que tenga el merge — verifica que B desaparece del listing).
6. Re-abre el modal de similares en A: ya no hay candidatos.
7. Crea (vía `POST /memories` desde el panel o curl) una nueva memoria
   con contenido parecido a A. F5 sobre el listing — el badge "1
   similar" reaparece.
8. Settings → Memorias → sube el threshold a `0.99` → el badge
   desaparece (cos 0.92 no llega). Baja a `0.5` → el badge reaparece.
9. Memoria D (sin embedding) no aparece como candidata en ningún
   modal.

**Checklist**:

- [ ] Badge "N similares" amarillo y clickable en la card de A.
- [ ] Modal lista candidatos con % de similitud visible.
- [ ] "Fusionar" funde contenido y soft-deletes el candidato.
- [ ] "Descartar" soft-deletes el candidato sin tocar la actual.
- [ ] Bajar threshold a 0.5 aumenta candidatos; subirlo a 0.99 los
      hace desaparecer.
- [ ] Memoria sin embedding (D) NO aparece como candidata.

**Pitfalls conocidos**:

- Si el badge no aparece, ejecuta el seed y revisa
  `cos(A,B) = 0.9XX` en la salida — si está por debajo del threshold
  default (0.85) los embeddings se generaron raros y hay que volver a
  correrlo (la semilla está fijada, pero pgvector puede normalizar
  distinto entre versiones).
- El modal hace SQL contra el endpoint `/memories/{id}/similar`. Si
  responde 422 con un mensaje sobre `pgvector cast`, te has comido el
  bug del Plan 06.6 — está fixeado en master.

## Troubleshooting

| Síntoma                                         | Causa probable                           | Fix                                                             |
| ----------------------------------------------- | ---------------------------------------- | --------------------------------------------------------------- |
| `cos(A,B)` bajo en el seed                      | pgvector normaliza distinto              | Re-correr el seed; si persiste, sube el `noise` y resiembra     |
| `PUT /tenant-settings/memories/threshold` → 422 | Settings registry rechaza el valor       | Revisa `settings_registry.py` — el rango esperado es 0.5 a 0.99 |
| El badge "N similares" no aparece               | Cosine < threshold actual                | Baja el threshold a 0.5 en `/admin/settings/memories`           |
| Modal de similares hace flash y se cierra       | `/memories/{id}/similar` devolviendo 5xx | Mira la consola del navegador + logs del api-server             |

Errores transversales viven en `docs/03-guides/gotchas/`.

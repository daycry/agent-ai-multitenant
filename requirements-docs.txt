# Documentation site toolchain (MkDocs + Material + static-i18n).
#
# Kept apart from the application dependencies on purpose: nothing in
# apps/ or packages/ imports any of this, and the docs job in
# .github/workflows/docs.yml is the only consumer. Adding it to
# constraints.txt would drag a static-site generator into every
# service image for no reason.
#
# FULLY PINNED, transitive dependencies included, and not by taste:
# `docs/03-guides/gotchas/ci-tool-version-drift.md` is this repo's
# account of what a loose pin costs — a toolchain that passes locally
# and rewrites files in CI with the same declared version on both
# sides. A docs build that renders differently depending on the day
# the runner's cache was created is the same defect.
#
# To upgrade: bump the direct dependencies below, run
#   pip install -r requirements-docs.txt --upgrade
#   pip freeze
# in a clean virtualenv, and paste the result back here. Then run
# `mkdocs build --strict` before committing — that is the gate.
